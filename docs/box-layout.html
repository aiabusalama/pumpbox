Wire colours · function

Cable management. Ferrules crimped on every stranded end; heat-shrink wire-number markers at both ends. Commons are DIN terminal blocks bridged by jumper bars into a bus (+5V / +12V / +24V / GND, plus the 143V± bus). Runs sit in slotted trunking (wire duct) between rows; field cables leave through PG-16 glands at the bottom edge.
